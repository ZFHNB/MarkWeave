## 一、Typora 功能全集（逆向清点结果）

### 1.1 Markdown 语法（Docs/Markdown Reference.md）

| 语法 | Typora 行为 | MarkWeave 现状 |
| --- | --- | --- |
| 段落 / 软换行 / 硬换行 | Shift+Enter 软换行，行尾两空格或 `<br/>` 硬换行 | ✅ 基本支持（hard_break） |
| 标题 H1–H6、setext 可选 | `#` 输入即成标题，菜单可升降级 | ✅ ATX；❌ 升降级命令 |
| 引用（可嵌套） | `>` 输入即成，自动续行 | ✅ 基本 |
| 无序/有序/任务列表（可嵌套） | `*`/`-`/`+`，`1.`，`- [ ]`；缩进/反缩进；勾选切换 | ✅ 基本；❌ 拖拽排序、❌ 任务状态菜单 |
| 围栏代码块 | 语言标签、行号选项、自动缩进 | ✅ 语言下拉 + 高亮；❌ 行号 |
| 数学块 / 行内数学 | MathJax，可自动编号、physics 包 | ✅ KaTeX 块；❌ 行内数学解析、❌ 编号 |
| 表格（GFM） | 工具条：调整行列、对齐、删除；右键 13 项操作；拖拽移动行列 | ✅ 多数；❌ 拖拽移动、❌ 表格尺寸弹层 |
| 脚注 `[^id]` | 悬浮查看、末尾生成脚注区 | ❌ 未实现 |
| 分隔线 | `---` / `***` | ✅ |
| YAML Front Matter | 顶部元数据折叠卡 | ❌ 未实现 |
| 目录 `[toc]` | 自动生成、随标题更新 | ❌ 未实现 |
| 行内公式 `$...$` | 可开关渲染 | ❌ 未解析 |
| 下标 `~x~` / 上标 `^x^` / 高亮 `==x==` | 偏好设置可开关 | ❌ 未实现 |
| 下划线 `<u>` | 原始 HTML | ⚠️ 仅 html:true 透传 |
| 删除线 | `~~x~~` | ✅ |
| 链接：行内 / 引用式 / 自动链接 | `[a][id]` + `[id]: url`；`<url>`；自动识别 www | ⚠️ 仅行内；❌ 引用式；❌ 自动链接 |
| 内部锚点 `#heading` | Ctrl+点击跳转 | ❌ |
| 图片 | 行内/HTML；缩放、对齐、相对路径、root-url | ⚠️ 仅基础行内 |
| Emoji `:smile:` | ESC 触发补全 | ❌ |
| HTML 块 / 行内 HTML / iframe / video | 原样保留并可渲染 | ⚠️ html:true 但无编辑语义 |
| 注释 `<!-- -->` | 灰显 | ❌ |

## 三、分阶段实施计划

> 原则：每阶段独立可交付、可回归；先语义后交互，先编辑后文件，先本地后导出。

### P1 — Markdown 语义补全（编辑器内核）✅ 已完成
**状态**：高亮/上标/下标/行内公式、YAML Front Matter、TOC、脚注（含悬浮预览）、Emoji（解析 + 自动补全）、引用式链接、内部锚点已全部落地并通过往返测试。
**目标**：把 GFM + Typora 扩展语法全部纳入 schema 与双向序列化。

1. Schema 扩展：`highlight` / `superscript` / `subscript` / `underline` mark；`footnote_ref` / `footnote_def` 节点；`toc` 块节点；`yaml_frontmatter` 块节点；`html_block` / `html_inline`；`emoji` 文本（直接保留 `:smile:`）。
2. 解析：markdown-it 插件或预处理 —— 行内公式 `$...$`、`==高亮==`、`^上标^`、`~下标~`、脚注、引用式链接、自动链接、TOC、YAML。
3. 序列化：所有新增节点/标记双向保真；引用式链接定义块保留。
4. 输入规则：`==x==`、`^x^`、`~x~`、`$x$` 即时转换；`[toc]`、`---` front matter、`[^id]` 自动补全。
5. 渲染：脚注悬浮/点击跳转、TOC 实时生成、YAML 折叠卡、HTML 块可切换源码。
6. 测试：往返单测覆盖每种语法 + E2E 输入规则。

### P2 — 编辑命令与查找替换 ✅ 已完成
1. 查找/替换面板：Ctrl+F / Ctrl+H，大小写、全字、正则、`n/N` 计数、上一个/下一个、全部替换、高亮与滚动定位。
2. 跳转到顶部/选区/底部；按行/句/词/样式选择与删除。
3. 复制为 Markdown / HTML / 纯 HTML / 图片 / MathML / TeX；粘贴为纯文本。
4. 清除格式、标题升降级、任务状态切换、缩进/反缩进快捷键完善。
5. 代码块自动缩进、复制代码内容。

### P3 — 文件工作流 ✅ 已完成（编码重开除外）
1. 打开文件夹 + 文件树/文章列表双视图、排序、过滤。
2. 快速打开（Ctrl+P）模糊搜索、最近文件/文件夹。
3. 新建文件/文件夹、重命名、复制、移动、删除、在资源管理器中显示。
4. 外部修改检测与重载、编码重开、CRLF/LF 切换。
5. 自动保存 + 草稿恢复（IndexedDB）。

### P4 — 视图与桌面交互 ✅ 已完成（窗口置顶/新窗口除外）
1. 多标签页（新建/关闭/切换/重新打开关闭的标签）。
2. 专注模式（当前块高亮 + 上下文淡出）、真正的打字机模式（光标垂直居中）。
3. 大纲折叠/展开/过滤/当前标题高亮/平铺；选区字数统计。
4. 右键菜单族：通用、块样式、内联样式、表格、图片、插入、大纲、文件、搜索。
5. 窗口置顶、新窗口、全屏、状态栏开关、拖拽打开、文件关联。

### P5 — 图片工作流 ✅ 已完成（上传器除外）
1. 插入本地图片对话框、拖放、剪贴板图片粘贴。
2. 复制到指定文件夹（YAML `typora-copy-images-to` + 全局设置）、相对路径、`typora-root-url`。
3. 图片 NodeView：缩放、对齐、图注、悬浮工具条、Markdown/HTML 语法切换。
4. 上传器接口（PicGo / 自定义命令）、失败回退。
5. 重新加载全部图片、删除图片/图片文件。

### P6 — 导出与打印（进行中）
1. 独立 HTML：内联主题 CSS、KaTeX、Mermaid SVG、图片内嵌。
2. PDF：分页、页眉页脚、纸张、页码、页边距、目录侧栏、深浅主题。
3. Pandoc 桥：检测安装、导入/导出多格式、导出设置模板。
4. 导出模板与 YAML 覆盖。

### P7 — 外观与偏好
1. 内置主题移植（github/newsprint/night/pixyll/whitey）+ 自定义主题文件夹。
2. 独立深色主题、跟随系统。
3. 偏好设置面板扩展至 Typora 全集（General/Editor/Markdown/Appearance/Save&Recover/Security/Advanced）。
4. 字体族/字号/行距/缩进/自动配对/智能标点。

### P8 — 质量与发布
1. 单元测试覆盖新增语法与命令；E2E 扩展。
2. 性能：大文档、长表格、多标签。
3. 可访问性、键盘导航、ARIA。
4. 代码签名（如需公开分发）与自动更新。

## 四、实施约定

- 每阶段结束运行：`npm run build`、`npm test`、`node scripts/test-e2e.mjs`，全绿才进入下一阶段。
- 新增功能必须同时有单测（序列化/纯函数）或 E2E（交互）。
- 不为单个测试写特判；序列化以“往返幂等”为准。
- Markdown 始终是可逆真源；专有元数据只允许出现在注释语法中。
- 与 Typora 行为不一致时，以 Typora 官方文档与实际安装行为为准，不做“看起来像”的实现。
